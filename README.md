# CareerOS

Official CareerOS installers by JR Academy. This repository contains installers and release automation, with no application source code.

macOS: see the [latest stable release](https://github.com/JR-Academy-AI/careeros-releases/releases/latest). Developer ID signed and notarized by JR Academy Pty Ltd.

Windows previews use separate entries in [all releases](https://github.com/JR-Academy-AI/careeros-releases/releases). Windows preview installers are unsigned; check each release's system requirements, validation scope and SHA-256 before downloading. They do not replace the stable Mac release.
